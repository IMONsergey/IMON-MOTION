# UI Product Demo

Run `npm run plan -- "<brief>"`, then prefer the product-capture path when demonstrating a real interface.

Primary patterns:
- `scene.ui-feature`
- `ui.cursor-focus`
- `ui.viewport-push`
- `ui.layered-product-frame`
- `reveal.precision-rise`

Use `adapters/product-capture` for exact element geometry and safe-to-show guards. Until its browser runner is marked ready, capture may require an explicit approved fixture/state rather than invented geometry.

Research is normally bounded to `remotion-cinematic`, `video-shotcraft`, `onda`, and `remotion-skills`.

Hard failures:
- cursor teleportation;
- fake UI presented as a real product state without disclosure;
- camera motion faster than comprehension;
- private/customer data in captures;
- action without a settled readable result state.
