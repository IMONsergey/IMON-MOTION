# Kinetic Typography

Run `npm run plan -- "<brief>"` and use the generated delivery/fps constraints before timing text.

Primary primitives/patterns:
- `scene.editorial-statement`
- `typography.word-stagger`
- `typography.line-reveal`
- `typography.metric-counter` when numerical proof is central
- `transition.match-move`
- `audio.beat-map` only when audio genuinely drives edit rhythm.

Research the routed subset of `motion-design-skill`, `motion-skills`, `onda`, `emilkowalski-skills`, `remotion-scenes`.

Rules:
- readable final state before expressive flourish;
- one dominant text behavior per beat;
- stagger follows syntax/emphasis, not every word equally;
- avoid random directions, per-word effects and constant movement;
- hold critical copy long enough to read at target platform size.
