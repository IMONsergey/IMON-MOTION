# IMON MOTION Director

Use this skill first for new video/composition work.

## Required execution

1. Run `npm run plan -- "<brief>"`.
2. Inspect delivery constraints, runtime blockers and QA level.
3. Run `npm run context -- "<brief>"` when model context must be materialized.
4. Read `core/creative-director/PROTOCOL.md`.
5. Establish focal/grid/type/surface/motion/camera/transition/audio/rest rules.
6. Revise the generated storyboard only when the actual brief justifies it.
7. Implement through normalized runtime/library/adapters; raw `upstream/**` is research only.
8. Use the generated QA plan before completion.

## Hard rules

- One primary message and one dominant motion idea per scene.
- Camera movement must reveal/follow/bridge something meaningful.
- Named brand references become principles, not copied branded graphics.
- Do not hide `adapter-required` blockers.
- Do not load ignored donors without rerouting.
- Production UI must preserve product truth and privacy.
